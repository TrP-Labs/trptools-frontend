# Widget UX proof

Production Docker frontend and isolated real API/database fixtures. See [verification](../../../docs/WIDGET-UX-VERIFICATION.md) and `results.json` for the exercised interactions.

Screenshots show desktop editing and the picker, touch editing at 375px and 320px, the customized mobile homepage, and the reorganized group/shift/route and settings pages. All captures use the existing dim theme. Generated fixture credentials are not included.

The `default-user-*` and `default-host-*` captures verify the sizing follow-up at 1440, 1024, 768, 375 and 320px. Cards sharing a desktop/tablet row align at both edges; mobile cards retain natural heights. `default-user-empty-1440.png` covers empty states.
